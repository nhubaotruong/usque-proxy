## Battery baseline (deferred — emulator not usable for this app)

**Status: DEFERRED to real-device QA.** No battery numbers were recorded in this
task. The emulator path was attempted and is blocked on this host:

1. The production APK ships **arm64-v8a only** (`ndk.abiFilters` in
   `app/build.gradle.kts`; `libgojni.so` is the only native lib in the APK).
2. This host is x86_64. The Android emulator refuses to run an arm64 system image
   on an x86_64 host: `FATAL | Avd's CPU Architecture 'arm64' is not supported by
   the QEMU2 emulator on x86_64 host. System image must match the host
   architecture.`
3. Installing the arm64-only APK on an x86_64 emulator boots and renders the UI,
   but the process dies with a native `SIGILL` the moment Go code loads
   (`Usquebind.register()` → `libgojni.so` arm64 on x86_64).
4. No physical device is attached (`adb devices` empty), and no WARP credentials
   were needed anyway (the app supports anonymous WARP registration).

### How to record the baseline later (real device)

On an arm64 Android 15+ device with the debug APK installed:

```bash
# 1. Install and launch, register (anonymous WARP), tap Connect
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.nhubaotruong.usqueproxy/.MainActivity
# (UI: Settings tab → "Register Device" → Home tab → "Connect")

# 2. Wait 10 minutes with the tunnel connected, then:
adb shell dumpsys batterystats | grep -A5 com.nhubaotruong.usqueproxy
adb shell dumpsys alarm | grep -A5 usqueproxy
adb logcat -d | grep -c "getStats"
```

Record the three numbers here and in the Task 10 report for comparison.
